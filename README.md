# Chamundeshwari — Fashion Designer Portfolio

An editorial portfolio showcasing fashion designer Chamundeshwari's collections: **Ice**, **Mirror**, and **Noir**. Features couture exploration through shimmer, hand-cut mirror tiles, and sheer structural tulle.

## Collections Featured

- **Ice**: Crystalline embellishment, frost hues, and sculptural winter silhouettes.
- **Mirror**: Hand-cut reflective geometric tiling with bespoke artisanal embroidery.
- **Noir**: Dramatic midnight tones, contrasting textures, and sheer architectural drape.

## Tech Stack

- **Framework**: TanStack Start & React 19
- **Routing**: TanStack Router (file-based)
- **Styling**: Tailwind CSS
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Build & Server**: Vite & Nitro

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

### Production Build

```sh
npm run build
```

### Preview

```sh
npm run preview
```
